# Customer Behavior Analysis Dashboard

## 📊 Project Overview

The **Customer Behavior Analysis Dashboard** is a data analytics project that explores e-commerce customer behavior, spending patterns, satisfaction levels, membership performance, discount usage, and potential customer churn risks.

The project uses Excel, Python, PostgreSQL, and Power BI to transform customer data into meaningful insights that can support data-driven business decisions.

## 🎯 Project Objectives

- Analyze customer spending patterns across different cities.
- Compare revenue generated by different membership types.
- Understand customer satisfaction levels.
- Examine the relationship between discount usage and customer satisfaction.
- Identify customers who may be at risk of churn based on their purchase recency.
- Categorize customers according to their risk levels.
- Present findings through an organized Power BI dashboard.

## 📁 Dataset Description

The dataset contains e-commerce customer information, including demographic details, purchasing behavior, membership information, and satisfaction ratings.

### Key Columns

| Column                   | Description                                       |
| ------------------------ | ------------------------------------------------- |
| Customer ID              | Unique identifier for each customer               |
| Gender                   | Customer gender                                   |
| Age                      | Customer age                                      |
| City                     | Customer location                                 |
| Membership Type          | Customer membership category                      |
| Total Spend              | Total amount spent by the customer                |
| Items Purchased          | Number of items purchased                         |
| Average Rating           | Customer's average rating                         |
| Discount Applied         | Indicates whether a discount was applied          |
| Days Since Last Purchase | Number of days since the customer's last purchase |
| Satisfaction Level       | Customer satisfaction category                    |

## 🔄 Project Workflow

1. **Data Collection:** Imported the customer behavior dataset into the analysis workflow.
2. **Data Cleaning:** Inspected missing values, checked column names, and prepared the dataset for analysis using Excel and Python.
3. **SQL Analysis:** Used PostgreSQL queries to analyze customer spending, revenue, membership performance, and customer behavior.
4. **Data Visualization:** Created charts, tables, and analytical visuals in Power BI.
5. **Dashboard Development:** Organized the visuals into a customer behavior dashboard to support easier interpretation of the results.
6. **Documentation:** Prepared project documentation, SQL queries, and dashboard screenshots for GitHub.

## 📈 Dashboard Features

### 1. Revenue Analysis by City

Compares customer spending across cities to identify differences in revenue contribution.

### 2. Revenue by Membership Type

Examines revenue across membership categories to understand their contribution to overall spending.

### 3. Customer Satisfaction Analysis

Visualizes the distribution of satisfied, neutral, and unsatisfied customers.

### 4. Discount and Satisfaction Analysis

Compares discount usage with customer satisfaction levels to explore possible relationships.

### 5. High-Value Customers at Risk

Highlights customers with relatively high spending and longer periods since their last purchase.

### 6. Customer Risk Categorization

Groups customers into risk categories based on the project's defined business rules.
