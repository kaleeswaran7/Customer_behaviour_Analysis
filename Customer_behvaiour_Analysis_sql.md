##### Data Cleaning: Your dataset contains missing values in Satisfaction Level. How would you handle those missing values before performing analysis?



SELECT COUNT(\*)

FROM customers

WHERE "Satisfaction Level" IS NULL;



SELECT

&#x20;   "Satisfaction Level",

&#x20;   COUNT(\*) AS customer\_count

FROM customers

WHERE "Satisfaction Level" IS NOT NULL

GROUP BY "Satisfaction Level";
